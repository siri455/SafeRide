## 🔄 Data Flow

### 1. App Launch Flow
```
User Opens App
    ↓
MainActivity.onCreate()
    ↓
Request Permissions
    ↓
Initialize Camera Preview
    ↓
Load Emergency Contacts from PreferencesManager
    ↓
Display UI
```

### 2. Add Contact Flow
```
User Taps "Add Contact"
    ↓
Show Dialog (dialog_add_contact.xml)
    ↓
User Enters Name & Phone
    ↓
Validate Input
    ↓
PreferencesManager.addEmergencyContact()
    ↓
Save to SharedPreferences (JSON via Gson)
    ↓
Update UI List
```

### 3. Start Monitoring Flow
```
User Taps "Start Monitoring"
    ↓
Check if contacts exist
    ↓
Start SafetyMonitoringService
    ↓
Service creates foreground notification
    ↓
[Module 2] Start drowsiness detection
    ↓
[Module 3] Start accident detection
    ↓
Update UI status to "Active"
```

### 4. Detection Flow [Future Modules]
```
[Module 2] Camera frames → Face Detection → Eye Analysis → Drowsiness Score
                                                              ↓
                                                    Threshold exceeded?
                                                              ↓
                                                    YES: Trigger Alert
                                                              ↓
                                                    Buzzer + Vibration

[Module 3] Accelerometer → Impact Detection → Accident Score
                                                    ↓
                                          Threshold exceeded?
                                                    ↓
                                          YES: Trigger Emergency
                                                    ↓
[Module 4]                                Get GPS Location
                                                    ↓
                                          Send SMS to Contacts
```

## 📦 Key Components Explained

### MainActivity.kt
- Main entry point of the app
- Manages UI and user interactions
- Handles permissions
- Controls camera preview
- Manages emergency contacts CRUD
- Starts/stops monitoring service

### SafetyMonitoringService.kt
- Runs as a foreground service (survives app close)
- Shows persistent notification
- Will host drowsiness & accident detection logic
- Runs continuously while monitoring is active

### PreferencesManager.kt
- Abstracts SharedPreferences access
- Serializes/deserializes objects using Gson
- Stores emergency contacts as JSON
- Stores user settings and preferences
- Thread-safe data access

### EmergencyContact.kt
- Simple data class
- Represents a single emergency contact
- Contains: name, phoneNumber

## 🎨 UI Components

### activity_main.xml
Main screen layout containing:
- Camera preview (PreviewView)

### dialog_add_contact.xml

## 🔐 Permissions Flow

```
App Launch
    ↓
PermissionX.init()
    ↓
Request: CAMERA, LOCATION, SMS, NOTIFICATIONS
    ↓
User Denies? → Show Explanation → Re-request
    ↓
Still Denies? → Show Settings Dialog
    ↓
All Granted? → Start Camera → Ready to Use
```

## 🎯 Key Design Decisions

1. **Pure Android Approach**: No external hardware needed
2. **Kotlin**: Modern, concise, null-safe
3. **CameraX**: Modern camera API, lifecycle-aware
4. **TensorFlow Lite**: On-device ML, privacy-focused
5. **SharedPreferences**: Simple, reliable local storage
6. **Foreground Service**: Ensures continuous monitoring
7. **Material Design**: Professional, familiar UI
